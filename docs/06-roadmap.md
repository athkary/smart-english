## ما أحتاجه منك قبل المراحل التالية
1. **قبل المرحلة 2:** اسم النطاق (domain) ومزود السحابة المفضل؛ Apple Developer Account (للتوقيع وTestFlight).
2. **قبل المرحلة 3:** مفتاح Anthropic API (يوضع في الخادم فقط).
3. **قبل المرحلة 4:** اختيار مزود STT/TTS (أقترح اختبار مزودَين فعلياً ثم الاختيار) + مفاتيحهما.
4. **قبل المرحلة 5:** مراجع تربوي للمحتوى العربي/الإنجليزي، وصوت أصلي للمفردات (TTS عالي الجودة أو تسجيل).
5. **قبل المرحلة 6:** حساب لمزود تقييم النطق (مثل Azure Speech).
6. **قبل الإطلاق:** مراجعة قانونية للخصوصية في أسواقك المستهدفة.
