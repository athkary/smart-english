# 07 — الخدمات والحسابات الخارجية المطلوبة

| الخدمة | لماذا | متى | أين يوضع المفتاح |
|--------|------|------|------------------|
| Apple Developer Program | التوقيع، الأجهزة الحقيقية، TestFlight، StoreKit | المرحلة 2 (للاختبار على الأجهزة) | Xcode / App Store Connect |
| GitHub (أو مكافئ) | المستودع + CI (يحتاج macOS runner للـiOS) | الآن | — |
| مزود سحابة (AWS / GCP / Azure / Fly.io …) | استضافة الخادم وPostgres وRedis المُدارة | قبل staging (المرحلة 2–3) | Secret Manager |
| نطاق (Domain) + شهادة TLS | `api.<domain>` | المرحلة 2 | — |
| Anthropic API | عقل المعلم (Claude) | المرحلة 3 | `ANTHROPIC_API_KEY` في الخادم فقط |
| مزود STT متدفق | التعرف على كلام الطالب | المرحلة 4 | متغير بيئة في الخادم |
| مزود TTS متدفق | صوت المعلمين (صوت لكل شخصية) | المرحلة 4 | متغير بيئة في الخادم |
| مزود تقييم نطق فونيمي (مثل Azure Pronunciation Assessment) | تقييم دقيق للنطق | المرحلة 6 | متغير بيئة في الخادم |
| تخزين ملفات (S3 أو مكافئ) + CDN | أصوات وصور المفردات المُراجعة | المرحلة 5 | IAM role للخادم |
| تتبع الأخطاء (Sentry أو مكافئ) | المراقبة | المرحلة 2 | DSN (غير سري نسبياً لكن يُحفظ في الخادم) |
| بريد معاملات (Postmark / SES …) | تأكيد حساب ولي الأمر، التقارير الأسبوعية | المرحلة 2/8 | متغير بيئة في الخادم |

لم يُفعّل أو يُختبر أي من هذه الخدمات حتى الآن.
