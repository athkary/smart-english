# 08 — دليل النشر خطوة بخطوة (مجاني)

ثلاث خدمات مجانية، ولا تحتاج بطاقة دفع ولا اسم نطاق:

| الجزء | الخدمة | الرابط الذي ستحصل عليه |
|------|--------|------------------------|
| واجهة التطبيق (ما يفتحه الأهل والأطفال) | **GitHub Pages** | `https://اسمك.github.io/smart-english/` |
| الخادم (API) | **Render** (خطة Free) | `https://smart-english-api.onrender.com` |
| قاعدة البيانات | **Neon** (خطة Free) | رابط اتصال سري تضعه في Render فقط |

> **لماذا Neon وليس قاعدة Render؟** قاعدة بيانات Render المجانية تنتهي بعد 30 يوماً من إنشائها. خطة Neon المجانية بلا مدة انتهاء ولا تحتاج بطاقة (1 GB لكل مشروع)، وهذا يكفي آلاف الحسابات.
>
> **ملاحظة عن Render المجاني:** الخادم ينام بعد 15 دقيقة بدون استخدام، وأول فتح بعدها يأخذ حوالي دقيقة. التطبيق يعرض رسالة «الخادم يستيقظ…» في هذه الحالة. عند الإطلاق الفعلي يمكن الترقية لخطة مدفوعة صغيرة.

---

## الخطوة 1 — رفع المشروع إلى GitHub (10 دقائق)
1. ادخل github.com بحسابك ← **New repository** ← الاسم: `smart-english` ← **Public** ← Create.
2. ارفع محتويات المجلد `smart-english-ai` كلها (بنفس طريقة رفع ملفات أذكاري: GitHub Desktop أو "Add file ← Upload files").
   - تأكد أن الملفات `render.yaml` و`.github/workflows/pages.yml` موجودة في الجذر.
3. لا يوجد أي سر في المستودع، فكونه عاماً آمن.

## الخطوة 2 — قاعدة البيانات على Neon (5 دقائق)
1. ادخل **neon.com** ← Sign up (يمكنك الدخول بحساب GitHub).
2. **Create project** ← الاسم `smart-english` ← المنطقة: أقرب منطقة لك (مثلاً Frankfurt / AWS eu-central-1).
3. من صفحة المشروع اضغط **Connect** وانسخ **Connection string** (يبدأ بـ `postgresql://` وينتهي بـ `sslmode=require`).
4. احتفظ به مؤقتاً — هذا سرّ، لا تضعه في GitHub أبداً.

## الخطوة 3 — الخادم على Render (10 دقائق)
1. ادخل **render.com** ← Sign up بحساب GitHub.
2. **New ← Blueprint** ← اختر المستودع `smart-english` ← Render يقرأ `render.yaml` تلقائياً.
3. سيطلب قيمتين:
   - `DATABASE_URL` ← الصق رابط Neon من الخطوة 2.
   - `CORS_ORIGINS` ← اكتب `https://اسمك.github.io` (بدون `/` في النهاية وبدون اسم المستودع). مثال: `https://athkary.github.io`
4. **Apply**. انتظر حتى تصبح الحالة **Live** (أول بناء 3–5 دقائق).
5. افتح `https://smart-english-api.onrender.com/ready` — يجب أن ترى `"status":"ready"`.
   - الخادم ينشئ جداول قاعدة البيانات تلقائياً في أول تشغيل.
   - إذا كان اسم الخدمة مختلفاً (لأن الاسم محجوز)، انسخ الرابط الفعلي من أعلى صفحة الخدمة في Render.

## الخطوة 4 — ربط الواجهة بالخادم (دقيقتان)
1. في GitHub افتح الملف `web/js/config.js` ← أيقونة القلم ✏️.
2. غيّر السطر:
   ```js
   const PRODUCTION_API = "https://smart-english-api.onrender.com";
   ```
   إلى رابط خادمك من Render إن كان مختلفاً ← **Commit changes**.

## الخطوة 5 — نشر الواجهة على GitHub Pages (3 دقائق)
1. في المستودع: **Settings ← Pages ← Source: GitHub Actions**.
2. اذهب إلى تبويب **Actions** ← "Deploy web app to GitHub Pages" ← **Run workflow** (أو أي Commit جديد يشغّله تلقائياً).
3. بعد اكتمال العلامة الخضراء ✅ افتح: `https://اسمك.github.io/smart-english/`

## الخطوة 6 — التجربة على الجوال
- **آيفون/آيباد:** افتح الرابط في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **أندرويد:** افتح الرابط في Chrome ← زر «تثبيت التطبيق» أو القائمة ⋮ ← «تثبيت التطبيق».
- جرّب: إنشاء حساب ← إضافة طفل ← تعيين رمز الأهل ← «ابدأ التعلم» ← اختيار المعلم ← زر الاستماع 🔊 ← «منطقة الأهل» بالرمز.

## إذا واجهت مشكلة
| العَرَض | السبب الأرجح | الحل |
|---------|--------------|------|
| «تعذّر الاتصال بالخادم» دائماً | `CORS_ORIGINS` غير مطابق أو رابط `config.js` خطأ | تأكد أن `CORS_ORIGINS` = `https://اسمك.github.io` بالضبط، ثم Manual Deploy في Render |
| `/ready` يعطي `not_ready` | رابط Neon خطأ | انسخ الرابط من Neon مرة أخرى وحدّث `DATABASE_URL` في Render ← Environment |
| أول فتح بطيء جداً | الخادم المجاني نائم | طبيعي؛ ينتظر حتى دقيقة |
| «محاولات كثيرة» | حماية ضد التخمين | انتظر 5–10 دقائق |
| Render يفشل في البناء | إصدار Python | في Render ← Environment غيّر `PYTHON_VERSION` إلى إصدار 3.13 متاح |

> **أرسل لي لقطة الشاشة أو رسالة الخطأ** وسأحدد المشكلة.

## الأسرار — أين توضع؟
| السر | المكان الوحيد المسموح |
|------|----------------------|
| رابط Neon (`DATABASE_URL`) | Render ← Environment |
| `JWT_SECRET` | يولّده Render تلقائياً |
| مفتاح Claude (المرحلة 3) | Render ← Environment فقط |
| **ممنوع** | أي ملف في GitHub أو في مجلد `web/` |
